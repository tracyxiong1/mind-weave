# 保存提示闪烁修复

验证日期：2026-10-14（Asia/Shanghai），版本 0.3.1。

## 问题与修复

连续平移、缩放或生成内容并发更新时，一轮最多 5 次保存后仍可能有新改动。旧代码把待保存队列未清空当作异常，弹出“画布持续更新中。草稿已保留，请稍后重试保存。”；之后保存成功又清除提示，导致顶部框反复出现。

现在每轮仍有次数上限，剩余改动在 180 ms 后继续保存。正常队列更新不显示失败提示；网络失败、保存失败和另一页面的人工冲突继续保留草稿并报告问题。

## 已通过的验证

- 先用单元测试复现旧提示，再验证修复后连续视图改动跨 8 次保存，最终视口落盘，期间无错误提示。
- 生成层连续触发 5 次版本冲突时，安静续存第 6 次，保留人工标题与最新生成内容。
- 真实 Chromium 在每次保存响应到达前继续平移，跨过原来的单轮上限；通过 MutationObserver 记录所有短暂出现的警告，而不仅检查最后一帧。警告记录为空，最终位置保存成功。
- 同一浏览器验收随即断网：真正失败仍显示警告，服务器保留最后成功版本，浏览器保留新草稿；恢复连接并刷新后补存成功。
- 类型检查、76 项单元测试、19 项浏览器测试、生产构建与 npm 0.3.1 安装闭环均通过。

测试使用合成对话，用户动图及分析帧保留在被 Git 忽略的私人验收目录，没有提交截图中的其他项目内容。
