# Excalidraw 迁移的功能对齐

核对日期：2026-11-02。默认入口、真实会话入口和 5180 兼容入口现已使用同一份正式实现。迁移保留 `CanvasApp` 的业务控制器、数据结构与保存链路，并替换场景和视口适配层。

## 一、原版能力

| 能力 | 正式实现与验证依据 |
| --- | --- |
| 真实会话加载、保存、CLI 回读、后续整理 | 保留 `CanvasLoader`、`LiveCanvasClient` 与本地 API；4 项 Codex 集成用例验证人工字段、位置和引用回读、离线重连、编辑期间暂缓更新 |
| 总根节点、多个独立分支 | 保留 `readingForest` 与 `positionsWithRoot`，总根同时投影到场景和 HTML 层；虚拟连线使用保留命名空间，避免与业务关系 ID 重名 |
| 整理布局、撤销 | 保留分支排列与一步业务撤销；刷新后仍可恢复原位置 |
| 展开、原文、完整消息与动态避让 | 继续使用 `NodeCard` 与真实 DOM 测量；保留保存锚点 |
| 拖动、键盘移动、新增落点 | 保留 `freePosition`、手势结束后单步提交和临时避让 |
| 人工关系默认显示 | 原生场景与命中层共用包含 `edge.userCreated` 的显示条件 |
| 点击关系和避障 | 原路由采样为原生线段；SVG 路径仅承担可访问的关系操作命中，复用相同几何 |
| 全局笔记、空画布笔记、连接、合并、删除 | 保留原全局入口、空状态与节点菜单，使用原业务命令 |
| 稳定引用、旧引用、URL hash | 保留同一解析器；改名与合并后仍可定位，删除与错误状态明确区分 |
| 键盘、焦点和窄屏 | 保留 Enter/F2/Esc/删除、方向键移动、焦点移入视口和 390px 预览 |
| 撤销与重做 | 原持久化历史保留 40 步；原生场景更新使用 `CaptureUpdateAction.NEVER`，不会生成第二套业务历史 |
| 系统、浅色、深色主题 | 跟随系统变化；明暗只改变配色，布局与尺寸一致 |
| JSON 导出、坏数据下载与恢复、容量不足 | 保留原文档导出、原始数据备份、显式恢复与保存失败提示 |
| 三个样例、关闭重开、选择和视口恢复 | 使用原默认入口与文档视图状态 |

验证入口为 `tests/canvas.spec.ts` 的 18 项原版交互用例和 `tests/codex.spec.ts` 的 4 项真实保存链路用例。所有用例统一捕获浏览器异常，避免仅凭 DOM 断言遗漏引擎错误。

## 二、验证页反馈的保留

- 卡片使用单层边框，无手绘重边、外链角标或原生嵌入激活提示。
- 阅读使用 `viewModeEnabled`，业务选择保留普通灰阶边框；原生交互画布没有紫色选框像素。
- 示例详情来自示例对话；未讨论建议保留“尚未讨论”。已知旧示例说明的更新保留人工字段、历史、自定义正文和增量后缀。
- 保留标题、摘要与稳定引用查找，可用 Ctrl / ⌘ + K 打开。
- 同地址的旧验证草稿仅在正式草稿缺失时迁入，来源范围重新校验，旧缓存作为备份保留。

上述范围另由 `tests/excalidraw.spec.ts` 的 4 项用例，以及草稿迁移和曲线路由的 9 项单元测试覆盖。

## 三、后续扩展

原版本来只导出 JSON。完整卡片 PNG/SVG 导出、任意原生图形、原生框选、自由绘图和复制粘贴尚未接入业务保存；正式页面不展示这些工具。多人协作还需要独立的传输、身份和冲突规则。

早期原型差异已由本次迁移处理；原型历史结果保留在 [独立原型记录](prototype.md)，当前总体验收见 [迁移记录](README.md)。
